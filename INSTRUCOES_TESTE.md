# Roteiro de teste da aplicação

A aplicação já está disponível para acesso. Este roteiro serve somente para validar as telas e as funcionalidades pelo navegador.

## Acesso

Abra o endereço publicado da aplicação e confirme que o Dashboard é exibido sem erro.

## Teste funcional no navegador

1. Abra o Dashboard e confirme que a página carrega.
2. Acesse **Empresas / CNPJs**.
3. Cadastre uma empresa usando um certificado A1 válido.
4. Acesse **Consultar SEFAZ** e selecione a empresa cadastrada.
5. Execute a consulta e confira as mensagens exibidas.
6. Acesse **Importar XML** e envie um XML válido.
7. Confira o documento em **Documentos**.
8. Acesse **XML → PDF** e gere o PDF.
9. Teste os botões **Baixar XML** e **Gerar PDF**.

## Resultado esperado

A aplicação está funcionando quando:

- o Dashboard abre no navegador;
- XMLs podem ser importados;
- documentos aparecem na lista;
- PDFs são gerados e baixados;
- mensagens de sucesso ou erro aparecem corretamente;
- os formulários impedem o envio de dados obrigatórios vazios;
- a navegação entre as telas funciona sem apresentar erro.
